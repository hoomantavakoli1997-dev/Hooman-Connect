# Hooman Connect — نسخه منبع 0.4.0 + ساخت خودکار APK

این مخزن عمومی برای توسعه Hooman Connect است. با هر push به شاخه `main` یا اجرای دستی workflow، GitHub Actions تلاش می‌کند APK آزمایشی (debug) را بسازد و به‌صورت Artifact ارائه کند.

## دریافت APK بدون Android Studio
1. مخزن را در GitHub باز کن.
2. وارد زبانه **Actions** شو.
3. اجرای **Build Android APK** را انتخاب کن و در صورت نیاز **Run workflow** را بزن.
4. پس از پایان موفق، در همان اجرای workflow بخش **Artifacts** فایل `hooman-connect-debug-apk` را دریافت کن.
5. فایل ZIP خروجی را باز کن؛ APK داخل آن `app-debug.apk` نام دارد.

## وضعیت واقعی برنامه — مهم
- این نسخه شامل رابط کاربری، مدیریت پروفایل و ذخیره رمزنگاری‌شده محلی است.
- موتور sing-box/libbox هنوز به چرخه VPN متصل نشده است.
- سرویس فعلی عمداً اتصال جعلی نشان نمی‌دهد و بدون هسته واقعی تونل نمی‌سازد.
- بنابراین حتی اگر workflow با موفقیت APK بسازد، این نسخه هنوز VPN عملیاتی نیست.
- ساخت موفق در GitHub Actions به معنی تست روی گوشی یا تأیید کارکرد شبکه نیست. پیش از معرفی نسخه به‌عنوان آماده، باید هسته رسمی اضافه، پیکربندی‌ها اعتبارسنجی و تست دستگاه انجام شود.

## پیش‌نیازهای ساخت خودکار
Workflow از JDK 17، Gradle 8.9، Android SDK 35 و Build Tools 35 استفاده می‌کند. نیازی به فایل `local.properties` یا نصب Android Studio برای ساخت آنلاین نیست.
